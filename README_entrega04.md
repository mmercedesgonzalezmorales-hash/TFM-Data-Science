# Entrega 04 · Cómo ver el mockup

```bash
python src/frontal_mockup.py   # lee results/ (Entrega 03) y genera docs/entregas/mockup/datos_mockup.js
```

Después, abrir `docs/entregas/mockup/04_mockup.html` en el navegador. Es interactivo: se pueden pulsar municipios, buscar, cambiar entre renta y contratos y filtrar por ola.

Documento de la entrega: `docs/entregas/04_diseno_frontal_ux.md`

| Ruta | Contenido |
|---|---|
| `docs/entregas/img/04_mockup_*.png` | Capturas del mockup enlazadas desde el documento |
| `docs/entregas/mockup/04_mockup.html` | Prototipo del frontal (HTML + d3) |
| `docs/entregas/mockup/datos_mockup.js` | Datos del prototipo, generados desde `results/` |
| `docs/entregas/mockup/geometria_cataluna.js` | Límites municipales de Cataluña (IGN, CC BY 4.0, vía es-atlas) |
| `src/frontal_mockup.py` | Script que genera los datos del prototipo |
